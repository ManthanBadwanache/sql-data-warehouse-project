# Data Catalog

## Overview

The **Gold Layer** represents the business-ready data model of the Data Warehouse. It is designed using a **Star Schema** to support reporting, dashboards, and analytical workloads.

The Gold layer consists of:

* **Dimension Views** – Store descriptive business information.
* **Fact Views** – Store measurable business events.

---

# Gold Layer Objects

| Object               | Type           | Description                                                                      |
| -------------------- | -------------- | -------------------------------------------------------------------------------- |
| `gold.dim_customers` | Dimension View | Stores customer information enriched with demographic and geographic attributes. |
| `gold.dim_products`  | Dimension View | Stores product information enriched with category details.                       |
| `gold.fact_sales`    | Fact View      | Stores sales transactions linked to customer and product dimensions.             |

---

# 1. gold.dim_customers

## Purpose

Stores customer master data enriched with demographic and location information. This dimension is used to analyze customers across multiple business perspectives.

---

### Source Tables

* `silver.crm_cust_info`
* `silver.erp_cust_az12`
* `silver.erp_loc_a101`

---

### Primary Key

```text
customer_key
```

---

### Columns

| Column          | PostgreSQL Data Type | Description                                                |
| --------------- | -------------------- | ---------------------------------------------------------- |
| customer_key    | INTEGER              | Surrogate key generated by the data warehouse.             |
| customer_id     | INTEGER              | Original customer identifier from the CRM system.          |
| customer_number | VARCHAR(15)          | Business identifier used by the source CRM system.         |
| first_name      | VARCHAR(50)          | Customer's first name.                                     |
| last_name       | VARCHAR(50)          | Customer's last name.                                      |
| country         | VARCHAR(50)          | Customer's country of residence.                           |
| marital_status  | VARCHAR(10)          | Customer's marital status.                                 |
| gender          | VARCHAR(10)          | Customer's gender.                                         |
| birthdate       | DATE                 | Customer's date of birth.                                  |
| create_date     | DATE                 | Date the customer record was created in the source system. |

# 3. gold.fact_sales

## Purpose

Stores transactional sales records that reference the Customer and Product dimensions.

This table serves as the central fact table of the Star Schema.

---

### Source Table

* `silver.crm_sales_details`

---

### Foreign Keys

```text
customer_key → gold.dim_customers.customer_key

product_key → gold.dim_products.product_key
```

---

### Columns

| Column        | PostgreSQL Data Type | Description                                     |
| ------------- | -------------------- | ----------------------------------------------- |
| order_number  | VARCHAR(50)          | Unique sales order number.                      |
| product_key   | INTEGER              | Foreign key referencing the Product Dimension.  |
| customer_key  | INTEGER              | Foreign key referencing the Customer Dimension. |
| order_date    | DATE                 | Date the order was placed.                      |
| shipping_date | DATE                 | Date the order was shipped.                     |
| due_date      | DATE                 | Due date for the order.                         |
| sales_amount  | INTEGER              | Total sales amount for the transaction.         |
| quantity      | INTEGER              | Quantity of products sold.                      |
| price         | INTEGER              | Unit selling price.                             |

# Business Rules

### Customer Dimension

* Customer information originates from the CRM system.
* ERP provides additional demographic and geographic attributes.
* CRM gender takes precedence over ERP gender.

---

### Product Dimension

* Historical product records are excluded.
* Only active products (`prd_end_dt IS NULL`) are included.
* Product categories are enriched using ERP reference data.

---

### Sales Fact

* Business keys are replaced with surrogate keys.
* Measures include:

  * Sales Amount
  * Quantity
  * Unit Price
* Dimension lookups are performed using Customer and Product dimensions.

# Summary

The Gold layer provides a clean, business-oriented data model that supports analytical workloads using a dimensional (Star Schema) design.

It serves as the primary consumption layer of the Data Warehouse and enables consistent, reliable, and high-performance reporting across business domains.
